# LQS (Library Queue System) :D

Java based library reservation and queue management system designed to streamline the reservation of discussion rooms and track real time room capacities.

## Features
* **Student & Reservation Management:**
  * Captures student details
  * Generates alphanumeric reservation codes
* **Reservation & Room Output Window:**
  * Puts reservations for review before pushing them into a room's active queue
* **Room Queue Logic:**
  * Tracks room capacities
  * Manages queues across multiple rooms
