#LQS (Library Queue System)
Java based library reservation and queue management system designed
to streamline the reservation of discussion rooms and track real time room capacities 

##Features:
**student & reservation management **
- captures student details 
- generates alphanumeric reservation codes
**Reservation & Room output window**
- puts reservations for review before pushing them into a room's active queue
**Room queue logic**
- tracks room capacities
- managers queues across multiple rooms

##proj structure:
src/ - all java source code files
.gitignore - untracks files to keep the repo clean
doc/ - everything you need to know to make the proj :>
